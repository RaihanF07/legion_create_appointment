Legion Create Appointment.

Create Appointment menu appears in Odoo where staff can book salon or service appointments with customer, service, employee, date, and time fields. Appointments follow a Draft → Confirmed → Done workflow and generate auto-numbered IDs (SA-001), and a Create Invoice button on confirmed.

Key Features:

  • Complete Appointment Booking Workflow: Staff can book appointments capturing customer, service, assigned employee, date, and time all in one form. The four-state workflow Draft → Confirmed → Done → Cancelled with confirmation dialogs ensures no accidental state changes during busy service hours.
  • Auto-Generated Appointment Reference :Every appointment gets a unique sequential reference number (SA-001, SA-002) automatically generated on creation using an ir.sequence. This makes every appointment uniquely identifiable for tracking, searching, and referencing in conversations with customers.
  • One-Click Invoice Generation :A Create Invoice button automatically generates a complete customer invoice pre-filled with customer, service product, quantity 1, and correct list price without any manual re-entry. The invoice opens instantly in a popup form for review before posting to accounting.

Frequently Asked Questions

Can I book multiple appointments for the same customer on the same day?

Yes — no unique constraint exists on customer and date, so multiple appointments per customer per day are allowed and each gets its own unique SA reference number.

Can this module be used for businesses other than salons?

Yes — the fields are generic enough for any appointment-based service business including clinics, repair shops, and consultancies.
